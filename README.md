# Projeto Telecom X - Previsão de Churn

## Descrição
Este repositório contém o código e a documentação relacionados ao desafio da Telecom X, parte do curso de Ciência de Dados da Alura. O objetivo é analisar dados de clientes da Telecom X, prever a evasão (churn) e fornecer insights para estratégias de retenção. O projeto utiliza técnicas de machine learning e visualização de dados.

## Data
- Data de Criação: 06 de Agosto de 2025
- Horário: 14:02 (horário de Brasília)

## Estrutura do Repositório
- `TelecomX_Dados_Tratados.csv`: Dataset tratado contendo informações dos clientes (ID, gênero, tenure, serviços, custos, etc.).
- `Relatorio_Churn_TelecomX.txt`: Relatório exploratório inicial com estatísticas e visualizações.
- `main.py`: Script principal com o código para o modelo preditivo de churn.
- `README.md`: Este arquivo com instruções e informações gerais.
